Project source was authored for Christin John. The layout is based on the supplied Xiaomi remote reference image.

The Gradle launcher scripts `gradlew` and `gradlew.bat` are from Gradle v8.9.0 and retain their Apache License 2.0 notices. Gradle wrapper setup downloads the official Gradle wrapper JAR after verifying the checksum published by Gradle. See https://www.apache.org/licenses/LICENSE-2.0 and https://github.com/gradle/gradle.

Wire field facts and pairing behavior were checked against tronikos/androidtvremote2 (Apache License 2.0), which cites Google's Polo pairing protocol and louis49/androidtv-remote. Those projects' complete source files and generated protocol classes are not bundled. The codec and transports in this project were written for this app.

AndroidX, Kotlin and kotlinx.coroutines are resolved through Gradle, with their upstream licenses. Brand names in shortcut labels identify installed TV apps; they do not imply affiliation.

Streaming shortcut artwork is bundled as Android vector drawables, converted from the following Wikimedia Commons SVGs. The original paths and colors are preserved, including the Hotstar gradient. Source SVGs and the conversion script are in tools/brand-assets.

- YouTube: https://commons.wikimedia.org/wiki/File:YouTube_Logo_2017.svg (YouTube; PD-textlogo).
- Prime Video: https://commons.wikimedia.org/wiki/File:Prime_Video_logo_(2024).svg (Amazon.com, Inc.; PD-textlogo).
- Disney+ Hotstar: https://commons.wikimedia.org/wiki/File:Disney%2B_Hotstar_logo.svg (The Walt Disney Company; see source page for licensing).
