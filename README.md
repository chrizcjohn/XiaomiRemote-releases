# Xiaomi Remote — APK releases

Download the latest Android APK from [Releases](https://github.com/chrizcjohn/XiaomiRemote-releases/releases/latest).

This public repository contains signed app APKs and user documentation. App source code is maintained privately. No signing keys or credentials are published here.

## Install and update

- Requires Android 9 or newer and an Android TV with a compatible Remote Service.
- Download the APK, approve installation, and pair your phone with the TV on the same Wi-Fi using its displayed code.
- From v0.5.1, open **Settings → Check for updates** to check and download later releases without a GitHub account or token.
- Downloads require **Yes, download**. Before offering installation, the app checks the APK's size, SHA-256, package, version, and production signing certificate.
- Android asks you to approve installation and may require a one-time **Allow installs from Xiaomi Remote** permission. Play Protect may offer a scan.
- Production APK updates from v0.4.0 onward use the same signing key and preserve settings/pairing. Earlier debug-signed builds require a one-time uninstall before installing a production build.

The app is unofficial and is not affiliated with Xiaomi or Google. Compatibility with physical TVs and Bluetooth HID depends on device firmware. See release notes for validation and limitations.
